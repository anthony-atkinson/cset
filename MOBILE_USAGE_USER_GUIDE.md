# CSET Mobile Usage User Guide

## Overview

CSET's mobile-responsive design allows you to perform cybersecurity assessments on mobile devices, including tablets and smartphones. This guide covers how to effectively use CSET on mobile devices, optimize your workflow, and take advantage of mobile-specific features.

## Getting Started

### Supported Devices

#### Mobile Devices
- **Smartphones**: iOS 12+, Android 8+
- **Tablets**: iPad iOS 12+, Android tablets 8+
- **Screen Sizes**: 320px to 1200px width
- **Orientations**: Portrait and landscape modes

#### Browser Requirements
- **iOS Safari**: Latest version
- **Chrome Mobile**: Latest version
- **Firefox Mobile**: Latest version
- **Samsung Internet**: Latest version
- **Edge Mobile**: Latest version

### Initial Setup

#### 1. Access CSET
- **Direct URL**: Navigate to your CSET instance URL
- **Bookmark**: Add CSET to your mobile browser bookmarks
- **Home Screen**: Add CSET to your device home screen for app-like experience

#### 2. Authentication
- **Login**: Use your CSET credentials
- **Biometric Auth**: Enable biometric authentication if available
- **Remember Me**: Enable "Remember Me" for convenience
- **Multi-Factor Auth**: Complete MFA if required

#### 3. Mobile Optimization
- **Orientation**: Rotate device to preferred orientation
- **Zoom**: Set browser zoom to 100% for optimal display
- **Notifications**: Enable browser notifications for CSET
- **Offline Mode**: Enable offline capabilities for field work
